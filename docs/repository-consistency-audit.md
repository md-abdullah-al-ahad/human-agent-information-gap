**Date:** 2026-10-21  
**Method:** Read and cross-check the existing CSV, case reports, saved DOM/screenshot files, manifest, reanalysis JSON, and scripts. No site was revisited and no new agent experiment was run.

## What can be stated now

The repository contains a useful set of saved observations and concrete examples of modality and reporting problems. The reproducible unit counts are 323 item IDs and 1,010 agent-item rows. The exact Stage-4 arm label counts are documented in the [cross-site synthesis](../results/experiment-03/cross-site-benchmark-synthesis-report.md). The strongest specific findings are bounded: some image text is not in ordinary DOM text, some agents made unsupported stock or compatibility claims, some selected static-tool runs took longer, and a browser capture can itself be an anti-bot challenge. Claims about overall accuracy, causal effects, universal anti-bot bypass, or validated LWA-Web cost savings require a new adjudication or experiment and are not conclusions of the present artifacts.

The [worklist](../results/item-adjudication-worklist.csv) now links all historical rows to available capture files and marks documented disputes. Seven of the 11 flagged agent-item rows have hash-checked saved-pixel reviews; four remain unresolved or provisional. All other corrected outcomes remain blank. It does not replace the item-level source review required for aggregate scoring.
