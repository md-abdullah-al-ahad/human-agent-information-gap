## Central question

When a human can see or verify information on a website, where does that information become unavailable, go unexplored, or turn into an unsupported assertion in an AI agent's answer? The unit of analysis is an information item moving through the website surface, tool exposure, agent retrieval, and final report. The research is not primarily a contest between Qwen and Gemini or a general web-navigation leaderboard.

## Sequence the user asked for

1. **Find the failure points on real websites.** The user emphasized in-image data, visually encoded facts, dynamic content, ambiguous interface states, and other facts that an agent might miss or infer incorrectly. They chose Bangladeshi websites as the main regional focus and reduced a proposed 100-site expansion to 15 collected platforms.
2. **Measure the effect of tool access and cost.** Compare the same question set with and without Playwright where those arms truly exist. Record which facts could be retrieved, where the agent searched, whether it resorted to scripts or image inspection, and actual input, output, cached-token, cost, and elapsed-time figures. A tool's cost or benefit may differ by site and agent. Keep billed OpenRouter cost distinct from Gemini rate-card equivalents and byte-based token proxies.
3. **Use the failure analysis to build a genuinely lightweight agent tool.** The user's intended LWA-Web interface is an MCP tool an autonomous agent calls for a URL. The tool itself must acquire the page or declare an access block, retrieve relevant text and image evidence, return a compact representation with source provenance and honest unknown states, and avoid wasteful tool loops. Handing an agent a Markdown file prepared by another process is only an offline component check. Injecting ground-truth strings keyed to known image filenames is a fixture, not automatic OCR or a general solution.
4. **Later, derive website-side guidance and controlled validation.** Candidate ideas include semantic text for in-image facts, explicit stock and exclusion states, structured data, and compact agent-facing endpoints. A small controlled website was proposed to test whether specific design choices cause persistent failure modes. The user initially said to run no new experiment, then explicitly lifted that constraint for the offline new-agent pilot on 2026-10-21.
5. **Write a manuscript when the evidence and implementation support it.** The user rejected an earlier suggestion to write a paper immediately after a small pilot and later challenged optimistic publication claims. Paper timing and venue choice should follow corrected scoring, a faithful account of the tool, and the actual evidence; they are not the current primary task.
