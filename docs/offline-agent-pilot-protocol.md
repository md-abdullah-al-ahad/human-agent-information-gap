# Offline new-agent pilot: protocol and executed run

The [frozen manifest](../results/experiment-03/offline-agent-pilot-manifest.json) contains 20 scored capture-level questions from Chaldal, US-Bangla, Shwapno, Bangladesh National Portal, and 10 Minute School. Its two diagnostics are the blocked Biman capture and the disputed 10 Minute School download count. The manifest records the expected answer, item-specific rule, source locator, and SHA-256 of every reference. Its `frozen_not_run` status is a historical preparation marker and is deliberately unchanged so the packet's gold hash still verifies. After the user lifted the earlier no-new-experiment constraint, the [run](../results/experiment-03/offline-agent-pilot-run-20261021/report.md) completed on 2026-10-21.

Run `python3 scripts/prepare_offline_agent_pilot.py` to verify all source hashes and IDs. `--packet-dir PATH` copies only the saved DOMs, screenshots, and one testimonial crop into a separate packet with a `tasks.json` that omits expected answers and reference locators. Paths in `tasks.json` are relative to the packet root; the runner must resolve them to absolute paths before calling MCP. Start the MCP server with FastMCP and Pillow available, for example `uv run --with fastmcp --with Pillow python scripts/mcp_lite_extractor.py`. The gold manifest and historical case reports must stay outside the agent's accessible workspace. The agent should have only the prepared packet and the MCP tools, without a live-web tool or unrestricted repository access. The executed run denied ordinary file/web tools, but the snapshot server itself had no packet-root allowlist; the report records this isolation limit.

For each task, start a fresh agent context with at most 20 tool calls and 180 seconds of wall time. Give the question and its site's `page.html` to `inspect_web_evidence(..., mode="snapshot", image_paths=[...])`. The agent may call `inspect_evidence` and `inspect_image_crop` using the resulting capture and image hashes. The crop tool returns an MCP image plus the original-image coordinates and source hash. The agent must answer or abstain and cite observation IDs or an image hash with crop coordinates. It must not treat OCR alone, filenames, Buy buttons, or absent controls as verified answers. All answers concern the **saved capture**, not the current website. Record whether the user-local English/Bangla Tesseract runtime was enabled; do not mix OCR-enabled and OCR-disabled tasks in one scored run.

Freeze model/version, prompt, tool configuration, time and call budgets, and the packet hash before the run. Save the full trace, final answer, cited evidence, wall-clock time, tool byte counts, and any billing data the provider actually supplies. Do not infer billed cost or tokenizer counts from response length. Historical runs used different prompts and tool conditions, so comparing their published scores to this pilot would be descriptive, not a controlled causal estimate. A matched baseline with the same new agent and task packet would be a separate later experiment.

Score the 20 questions only after the traces are saved. Keep correctness and evidence grounding as separate fields:

- `exact_code` and `exact_entity`: exact value after Unicode normalization and whitespace cleanup; the parent name also accepts the explicitly listed `Purnima Laskar` transliteration. A different name or one-character code error fails.
- `exact_number`, `exact_quantity`, `price_and_minimum`, and `calendar_date`: normalize Bengali/Western digits, punctuation, and equivalent date formatting, while preserving the quantity, unit, threshold, and date. The Egg Loose case requires **both** price and minimum quantity.
- `complete_set`: every listed member is required, with no incorrect extra member. A subset is partial in a separate descriptive field, not a full pass.
- `normalized_literal` and `exact_key_phrase`: normalize Unicode and whitespace; minor punctuation/case differences are allowed for English text, but a changed Bengali key term is not. Do not infer a different claim from similar wording.
- `exact_visual_entity`: the rendered pixels determine the entity. An asset filename is not a valid substitute. A correct answer without a resolvable source citation is correct but ungrounded.

The blocked Biman and conflicting download-count diagnostics are excluded from the 20-question answer denominator. They test whether the agent reports `access_blocked` and reference uncertainty. Record abstentions separately from wrong assertions. Some reference crops have no independently recorded acquisition time, and one testimonial crop is supplied directly to the agent, making that item a reading test rather than a localization test. Do not generalize the pilot to current webpages, all 323 item IDs, or overall mitigation effectiveness.
