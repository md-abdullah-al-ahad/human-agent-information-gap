

Based strictly on the page:

**1. Customer support**
- Helpline: **16374**
- Operating hours: **7:00 AM to 11:00 PM**
- Support email: **info@shohoz.com**

**2. Cancellation & migration rules**
- Customers must have **12/24 hours before trip departure time** (depending on the operator).
- Migration: must call the helpline 16374.
- Cancellation via website is allowed if there's enough time (12/24 hours).
- Hours explicitly **excluded** from the cancellation window: **11 PM to 7 AM**.
- Strict rule for migration phone number: the customer **must call from the same ticket booking number** (the number used to book the ticket).

**3. Refund timeline**
- **bKash / Nagad:** maximum **5–7 working days**.
- **Internet banking / Debit cards / Credit cards:** maximum **7–10 working days**.

**4. Ticket search bar**
- **Trip types:** One Way, Round Way.
- **Fields:** From, To, Journey Date, Return Date (with a "+ Add Return Trip" option and a date calendar).
- **Actions:** "Search" button.

**5. Operators & single-account services**
- Operators: **100+ operators nationwide** (the page states "access to 100+ operators nationwide").
- Services under the single Shohoz account: **Bus, Air, Train, Launch, Event, and Park (Beta)** tickets.
